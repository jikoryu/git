📉 Amazon 价格走势查询

从商品页面直接提取真实价格，自动积累历史走势

🇺🇸 Amazon 京东 淘宝/天猫 拼多多
⭐ 推荐 · 无需扩展

方式一：拖拽书签

把下面按钮拖到浏览器书签栏。在 Amazon 商品页面点一下即可查看该商品的价格走势。

📉 View Price History
  • 确保书签栏可见（Chrome: Ctrl+Shift+B）
  • 把橙色按钮拖到书签栏上
  • 打开 Amazon 任意商品页 → 点书签 → 弹出价格走势
🤖 自动注入按钮

方式二：油猴脚本（商品页自动显示按钮）

安装后 Amazon 商品页右下角自动出现悬浮按钮，点击即可。支持 Amazon 全球 19 个站点。

安装脚本
  • 需先安装 Tampermonkey 扩展
  • 点击上方按钮 → Tampermonkey 自动识别 → 确认安装
  • 打开任意 Amazon 商品页面 → 右下角自动出现按钮

工作原理：从你正在浏览的商品页面 DOM 中提取真实价格，无需爬虫。
每次查询都会保存一条价格记录，历史走势随使用逐步累积。
